# DevOps & Cloud Operations Toolkit
A collection of PowerShell scripts, automation solutions, troubleshooting guides, proofs of concept (POCs), and infrastructure configuration files developed while working on Azure cloud operations and DevOps initiatives.



## Topics Covered
- Azure Virtual Machine Management
- Monitoring & Reporting
- Infrastructure Automation
- Incident Troubleshooting
- PowerShell Automation
- Azure Resource Management
- Operational Runbooks
- YAML-based Configurations
- DevOps Best Practices



## Purpose
The goal of this repository is to showcase practical solutions, automation techniques, and operational knowledge used to improve reliability, efficiency, and observability in cloud environments.



New scripts and operational use cases will be added regularly.
